# My E-Commerce Project

Этот проект создан в рамках домашнего задания по **объектно-ориентированному программированию (ООП)** для отработки навыков работы с классами и объектами.

Проект моделирует базовые сущности интернет-магазина — товары и категории товаров.

**Текущая версия:** реализовано наследование — классы `Smartphone` и `LawnGrass`, ограничения при сложении и добавлении продуктов.

## Реализованные классы

### `Product` (src/classes.py)

Класс для представления товара.

**Атрибуты:**
- `name` (str) — название товара.
- `description` (str) — описание.
- `price` (float, приватный `__price`) — цена. Доступна через геттер и сеттер; при попытке установить значение ≤ 0 выводится сообщение «Цена не должна быть нулевая или отрицательная» и цена не меняется.
- `quantity` (int) — количество в наличии.

**Методы:**
- `new_product(data: dict)` — класс-метод, создающий объект `Product` из словаря с ключами `name`, `description`, `price`, `quantity`.
- `__str__()` — возвращает строку вида `"Название продукта, X руб. Остаток: X шт."`.
- `__add__(other: Product)` — возвращает сумму произведений цены на количество для двух продуктов.

### `Category` (src/classes.py)

Класс для представления категории товаров.

**Атрибуты экземпляра:**
- `name` (str) — название категории.
- `description` (str) — описание категории.
- `products` (свойство-геттер) — возвращает строку с перечнем всех товаров в формате:  
  `"Название продукта, X руб. Остаток: X шт.\n"`. Сам список хранится в приватном атрибуте `__products`.

**Атрибуты класса:**
- `category_count` (int) — общее количество категорий (автоматически увеличивается при создании нового объекта `Category`).
- `product_count` (int) — общее количество товаров (увеличивается при инициализации категории и при вызове метода `add_product`).

**Методы:**
- `add_product(product: Product)` — добавляет переданный объект `Product` в приватный список товаров и увеличивает `product_count` на 1.
- `__str__()` — возвращает строку вида `"Название категории, количество продуктов: X шт."` (сумма `quantity` всех товаров).

### Функция `load_categories_from_json` (src/classes.py)

Загружает категории и продукты из JSON-файла. Формат файла должен соответствовать `data/products.json`.

**Пример вызова:**
```python
from src.classes import load_categories_from_json
categories = load_categories_from_json("data/products.json")
```
### Демонстрационный скрипт (main.py)
Демонстрирует создание продуктов, категорий, использование геттеров, сеттера цены, класс-метода new_product и метода add_product. Запускается командой:

## Наследование и полиморфизм (ООП)
### Классы-наследники
Smartphone — дочерний класс Product. Атрибуты: efficiency, model, memory, color.

LawnGrass — дочерний класс Product. Атрибуты: country, germination_period, color.

В конструкторах используется super().__init__ для инициализации атрибутов родителя.

### Ограничения
При сложении (__add__) проверяется тип; разные классы → TypeError.

Метод add_product принимает только Product или его наследников (isinstance).
